# Source attribution and scope

## sicilahval, 24 October 2026

`src/sicilahval/`, its portable skill, selected real examples, tests and bilingual methods notes are a new general-purpose extraction workflow by Fatih Kansoy, developed with AI-assisted software work. The design draws on source-review lessons from Jewish and Armenian personnel records: complete biographies and additions, calendar conflicts, payment components, legal wording and explicit inference. The full private documents, corpus, identity decisions and research-specific classification tables are not distributed. Two selected source transcriptions and their new-format readings are included with exact archival references at the owner’s explicit request. New code does not impose the research project's 92-column panel.

The methods notes cite Gülden Sarıyıldız’s 2009 encyclopedia entry on the registers; the entry is referenced, not reproduced. Invented fixtures remain confined to regression testing; the public demonstrations use actual source records. Software credit does not replace citation of a source publication or archival record. Apache-2.0 covers the original software, skill instructions and project-authored documentation, excluding identified source quotations and transcriptions. Historical excerpts retain any rights attached to their sources; this repository does not claim ownership or grant a separate license for them.

## Earlier Personnel Evidence Toolkit, 21 October 2026

The copied implementation originated in the **Ottoman Bureaucracy** research project, developed and maintained under Fatih Kansoy's direction with AI-assisted software work. The existing module is at `OttomanWage/bureaucracy/tools/public_personnel/` in the private research workspace. `SOURCE_MANIFEST.json` identifies each selected source file and its exact source/candidate SHA256 values.

The project owner approved this selected software release under Apache-2.0 on 21 October 2026. This statement describes software provenance and project maintenance; it does not claim authorship or ownership of underlying archival records or scholarly sources. Those materials are excluded from the release.

The public package directory is named `personnel_evidence`. In v0.1.3 its exporter explicitly closes the SQLite connection used to read back the output; the eight other copied files remain unchanged. `SOURCE_MANIFEST.json` retains the original source hashes and records this modification. Newly prepared documentation, `examples/synthetic_example.py` and `tests/test_offline.py` were created specifically for the earlier software release. No existing dataset or historical biography was used in that example or its tests. The synthetic fixture is deliberately implausible as historical evidence and must never be merged into a real research corpus.

Excluded from this first-module release: the provider API runner, runner-linked reprocessing, all real source inputs, original quote-heavy tests, raw/archive material, model requests/responses, usage logs, full dataset, identity-resolution decisions, website build, manuscript and econometric results. There is no assertion of public adoption, GitHub stars, contributors, downloads or a measured token-cost saving.
